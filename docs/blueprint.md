# **App Name**: Napoli Bites

## Core Features:

- Table Availability: Display available and unavailable tables with estimated availability time. 
- Menu Display: Showcase 10 pizza types with size options and allow up to 5 add-ons per pizza. Display 5 drink options.
- Order Type Selection: Enable users to choose between delivery, pickup, or dining in. Collect necessary details such as address for delivery.
- Payment Simulation: Simulate payment processing via Stripe, redirecting the user to a confirmation page post-payment.
- Invoice Generation: Generate a detailed invoice in UUID format with user data, order details, order type, and total amount including taxes. Offer options to view past order history.
- Multilingual Support: Support English, Spanish and Italian languages to cater to a diverse user base.

## Style Guidelines:

- Primary color: Saturated red (#D32F2F), inspired by the vibrant tomatoes of Neapolitan cuisine, providing an energetic and appetizing feel.
- Background color: Light, desaturated red (#F2E7E7), creating a warm and inviting atmosphere without overwhelming the senses.
- Accent color: Yellow-orange (#FFB300) to highlight important elements like prices and call-to-action buttons, reminiscent of cheese and the crust of a pizza.
- Classic, slightly rounded serif font for titles and headings to convey authenticity, and a simple, readable sans-serif font for body text to ensure a pleasant reading experience.
- Simple, line-based icons that reflect Italian culture, like scooters or chef hats.
- Use an infinite scroll layout on the main page, organized into sections for pizzas, drinks, and promotions, with clear, contrasting backgrounds to enhance readability. Make it mobile-responsive.
